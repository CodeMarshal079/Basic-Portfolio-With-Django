# Calorie Counter Web Application

A dynamic web application built with Python and Django designed to help users track their daily food intake, monitor calorie consumption, and maintain their personal fitness goals.

---

## 📌 Project Details
* **Framework:** Django (Python)
* **Main App:** `CaloryCounterApp`
* **Project Directory:** `Habib_15_CaloryCounter`
* **Project Type:** Web Application Development

---

## ✨ Features
* **Calorie Tracking:** Add daily food logs and calculate total calorie intake.
* **User Profiles:** Manage personal metrics (e.g., age, weight, height, daily calorie target).
* **Interactive Forms:** Forms to easily log meals and track daily goals.
* **Dashboard View:** Visual summary of daily calorie intake and progress toward health targets.
* **Admin Control:** Django admin integration to manage food items and user profiles.
