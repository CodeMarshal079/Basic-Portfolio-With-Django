# Personal Portfolio Web Application

A dynamic personal portfolio website built with Python and Django. This application lets users showcase their projects, skills, work experience, and education, featuring an admin dashboard and an automated CV/Resume generator.

---

## 📌 Project Details
* **Framework:** Django (Python)
* **App Name:** `Portfolio`
* **Project Type:** Level-4 Web Application Development

---

## ✨ Features
* **Authentication:** User Login and Registration pages.
* **Portfolio Showcase:** Displays skills, work experience, projects, and education.
* **Interactive Forms:** Contact form for visitor inquiries.
* **Admin Dashboard:** Allows admins to insert and update portfolio information.
* **Resume/CV View:** Generates an online Curriculum Vitae from stored data.
